A two-part micro-confession that was typed and never sent: a `To:` line naming who it was meant for, and the unsent message itself on one line. This version confesses a small, specific guilt — a borrowed library book kept since 2019 because returning it would mean admitting the friendship quietly faded — a reason it stayed in drafts that is too honest, and too late, to say out loud.

## Run it

```sh
npx tsx main.ts
```
